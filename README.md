# Portfólio — Guilherme do Amaral

Site estático em português, sem build ou dependências obrigatórias. Abra `index.html` ou execute `python -m http.server 8000` nesta pasta.

## GitHub Pages

Copie o conteúdo desta pasta para a raiz do repositório `Gui-Amaral2003.github.io`. Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)`.

As páginas usam caminhos relativos e também funcionam em um subdiretório. O portfólio substitui o antigo site de Visão Computacional.

## Conteúdo

- `index.html`: apresentação, projetos, experiência, sobre e contato.
- `projetos/`: três estudos de caso.
- `assets/style.css` e `assets/main.js`: estilos e interações.
- Currículo: download em `assets/curriculo-guilherme-amaral.pdf`, com publicação autorizada. O PDF acadêmico não está incluído.

Resultados B3 transcritos do PD fornecido. O filtro MM200 alterna resultados reportados, não executa modelos. CCEE: contagens são destinos mapeados no código; sem ganhos de desempenho estimados. Gemini_Code: diagnóstico e sugestões, sem correção automática ou reexecução.

Fonte opcional: Google Fonts, com fallback local. Nenhum segredo, conexão empresarial ou dado restrito é incluído.
